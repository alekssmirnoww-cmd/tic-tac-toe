Name: Python Tic-Tac-Toe Game

Description:
a classic tictactoe game created using Python   and built-in tkinter library. Two players will have to play by turns and place their marks (X and O) in the grid by clicking on the corresponding buttons and the application will automatically check whether there is a winner or it’s a tie game.

Prerequisites:
All you need in order to execute this project is the latest Python 3.x version installed on your computer. As the project utilizes only built-in libraries (tkinter), you do not have to install anything extra.

Installation/Execution Steps:
1. Save the source code of the project in a file tictactoe.py.
2. In the terminal or command prompt in the folder where the file tictactoe.py is located type in the following command:
python tictactoe.py

Project Features:
The project features an elegant 3x3 grid layout with buttons that allow the players to place their marks. It also includes win checking logic for rows, columns and diagonals, supports tie game (if all the 9 places are occupied) and automatically restarts the game.
